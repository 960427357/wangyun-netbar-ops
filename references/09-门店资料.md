# 旺云商户端 · 门店资料与运营配置技能手册 v1

> 路由前缀 `/admin`、`/serviceManage`、`/netBarSummary`，门店「演示门店」。
> 状态：2026-10-29 实测，字段为逐页抓取，未提交任何数据。
> 用途：门店资料、支付与钱包、短信、网吧配置开关、语音播报、机位图、通知宣传、交接班对账。

---

## 一、结论先行

1. 「网吧配置」八个 tab 是全站开关总闸：**商超开不开、能不能自助充值、能不能自助办会员、订座怎么收费**，都在这里。配了功能但前端看不到，先回这里查开关。
2. 移动端配置直接决定门店在**旺旺宝网吧版 app / 支付宝小程序**上长什么样（别名、人均、营业时间、室内图片）。
3. 钱包管理是**钱**：提现、不可提现明细、交易流水，两个按钮能提款，权限只给老板/股东。
4. 交接班是每天对账的入口，四个金额字段（上缴/留给下班/移动收入/核销收入）与总收入的关系要背下来。

## 二、场所与设备

### 2.1 场所管理 `/admin/systemSetting/place`

列：场所名称 / 审核状态 / 场所类型 / 场所编号 / 场所地址。按钮：搜 索 / 清 空 / **绑定** / 查看 / 编辑。

`场所编号` = 接口里的 placeCode（本店 00000000000000），所有计费接口都带它。多门店时对不上号先查这里。
`审核状态` 未通过会导致部分功能不可用（支付、团购上架）。

### 2.2 支付宝桌贴 `/admin/systemSetting/deviceManagement/zfbTouch`

两 tab：一体机 / 支付宝桌贴。
桌贴页字段：区域 / 序号区间（决定贴哪几台机）、收件人、手机号、收件地址、印刷场所名称。
按钮：提交订单 / 清 空 / 详情 / 去支付。
列表列：区域 / 序号区间 / 操作 / 采购时间 / 采购内容 / 状态。

下单即产生采购单，走「去支付」付款；这是**真实采购**，不要测试点击。

## 三、网吧配置 `/admin/systemSetting/netbarConfig/*`

八个 tab，均以「保 存」生效，是本手册最重要的一节。

### 3.1 基础配置 `base`

字段（全部为开关或单选）：

| 字段 | 含义 |
|---|---|
| 允许吧台修改商品在客户端销售 | 吧台能否改客户端可见性 |
| 允许会员余额（现金部分）购买商品 | 现金余额买货，影响赠送余额是否可用 |
| 允许客户端会员充值自定义金额 | 关掉就只能选固定档 |
| 客户端网民购买专场卡自动使用 | 买了卡是否自动开卡 |
| **是否开启商超** | 总开关，关了整个商超前端消失 |
| 购买商品是否自动打印小票 | |
| 客户端支付方式配置 | 现金 / 微信转账 / 支付宝转账 / POS 机（多选） |
| 控制台支付方式配置 | 同上，收银台侧 |
| 核销办理会员卡自定义密码 | |
| 长时间不来上网的顾客，是否自动删除会员 | 与「历史会员删除」联动 |
| 收银端商超下单/派送是否选择派送人 | |
| 客户端商超下单是否选择派送人 | |
| 是否允许美团抖音超时撤销核销 | 关掉后超时单只能走异常订单 |
| 允许支付宝小程序扫码上机\|激活 | 「碰一碰」类场景必需 |
| 交接班是否强制检测现金未派送 | 开启后交接班会拦 |
| 客户端是否允许自助办理会员 | 移动端拉新的前置开关 |
| 旺旺吧网吧版网费充值是否允许现金支付 | |
| 非销售时段展示商品，标注可售卖时间段 | 夜间商超展示 |

三大出处：商超开关、支付方式、自助办理会员。前端「没功能」九成在这三项。

### 3.2 充值策略 `recharge`

列：# / 策略名称 / 会员类型 / 充值金额 / 赠送金额 / 会员等级 / 会员日 / 网民自助购买 / 充值次数 / 适用场景。
按钮：搜 索 / 清 空 / **编辑充值次数** / **编辑适用场景**。

「网民自助购买」是移动端能否自己充值的关键；「充值次数」限制同一会员可享几次，做首充礼必填。

### 3.3 移动端配置 `wwbao`

字段：是否上架旺旺宝网吧版 / 是否允许办理会员 / 别名 / 联系电话 / 人均消费金额 / 服务标签 / 营业状态 / 营业时间 / 电脑配置 / 室内图片。按钮：+ 添加 / 保 存。
提示：「不填，默认为场所名称」。

这是门店在 app 上的门面。别名不填就显示「演示门店」，对外营业前必须改。

### 3.4 订座配置 `orderSeat`

字段：会员 / 临时卡 / 现金 / 现金+赠送（四类支付方式）、占座配置、订座配置。按钮：保 存。

四类支付按需勾选；不勾「现金」则到店付款的客人订不了座。

### 3.5 专场卡配置 `specialCardSet`

列：# / 专场卡名称 / 是否启用 / 允许网民自助购买 / 支持会员余额支付 / 销售对象 / 可用时间。
按钮：待使用专场卡 / 编辑销售对象 / 编辑可用时间。

这里管的是**已建好的专场卡**能不能在前面卖，卡本身在 `/msBarOptions/cards` 建。

### 3.6 补贴策略 `subsidyStrategy`

列：等级 / 赠送网费。按钮：新 增 / 编 辑 / 删 除。
按会员等级给网费补贴，和充值赠送是两笔，注意叠加后的总赠送率。

### 3.7 电脑配置 `computerConfig`

列：电脑名称 / 区域 / 配置信息。按钮：搜 索 / 清 空 / 批量设置 / 区域设置 / 修改电脑配置。
筛选：电脑名称、区域。

移动端展示的「电脑配置」就从这里取，配了才能在 app 上看到机位配置。

### 3.8 一体机配置 `ytjSet`

一体机（自助机）相关参数，与 `deviceManagement/wwbytj` 配套使用。

| 通知设置 | `/admin/systemSetting/staffNotice` | 列 岗位名称 / 消息通知类型；按钮「配置」；新增岗位后回来补 |

## 五、钱包与收款

### 5.1 网银钱包 `/admin/payManage/walletManage`

三 tab：交易流水 / 不可提现明细 / 提现明细。
列：消费项 / 可提现金额 / 交易手续费 / 交易金额 / 支付渠道 / 状态 / 类型 / 时间 / 商户单号 / 交易明细。
筛选：商户单号、消费项、支付方式、类型、时间。按钮：**提 现** / 查询 / 重置。

「可提现金额」与「不可提现明细」分开记：赠送余额、补贴属不可提现部分。

### 5.2 收款账号 `/admin/payManage/accountNumber`

按钮「修改开户信息」，字段 启用 / 停用。
换银行卡走这里，改动后需重新审核，期间收款可能中断。

## 六、服务管理 `/serviceManage`

### 6.1 语音播报 `/serviceManage/netBarVoiceManage/voiceConfig`

列：终端名称 / 终端 IP。按钮：添加终端 / 编辑 / 删除 / 保存。
子页：网吧语音管理 `voiceManage`、日常语音提醒 `audioDaily`、专呼语音 `dedicatedVoice`、客户端别名 `terminalName`。

「客户端别名」决定播报时怎么念机位（068 念成「六八号机」还是「零六八」），吵闹场子建议短别名。

### 6.2 机位图 `/serviceManage/netbarSite/*`

大屏机位图 `bigScreen`：列 # / 大屏名称 / 启用；按钮 新 增 / 查看 / 编辑。
APP 机位图（同页 tab，座位图列表 + 占座/订座限制）见下。

这里不配价格。机位归属区域在 `/msBarOptions/clients`。

#### 按机位开关占座 / 订座（实测 2026-10-29）

**这是全站唯一能按单台机位开关占座/订座的入口。** 3.4 订座配置页只管全局策略
（免费时长、取消退款、身份限制），某台机器参不参与，只能在 APP 机位图这里改。

路径：服务管理 → 机位图 → **APP机位图** tab → 滚到下方两个穿梭框：

| 区块 | 左框（不参与） | 右框（参与） |
|---|---|---|
| 网吧订座限制 | 不参与订座 | 参与订座 |
| 网吧占座限制 | 不参与占座 | 参与占座 |

标题旁的 `0/7` 是「已勾选数 / 该框总数」，不是参与数。**右框 = 参与，左框 = 不参与**，
语义是反的，容易看错。

操作（例：让 068 不参与占座）：

1. 服务管理 → 机位图 → APP机位图
2. 滚到「网吧占座限制」
3. 在**右框「参与占座」**里勾选 `068`
4. 点两框中间的**左箭头 `<`**，068 移到左框
5. 点该区块的「保 存」→ toast 回「操作成功」
6. **刷新复核**：左框应变 `0/1` 含 068，右框变 `0/6`

定位器要点：

- 两个穿梭框按 DOM 顺序取：`.el-transfer` 第 1 个 = 订座限制，第 2 个 = 占座限制。
- 左右面板：`.el-transfer-panel` 第 1 个 = 不参与侧，第 2 个 = 参与侧。
- 机位项：参与侧内 `.el-checkbox` 按文本匹配（`A002（包间2）` 带括号后缀，按前缀匹配更稳）。
- 箭头：`.el-transfer__button` 第 1 个 = 左移（参与→不参与），第 2 个 = 右移。
- **保存按钮有两个**，第 1 个属订座限制、第 2 个属占座限制，点错会保存错区块。
  可用包含文本的祖先容器定位，或取 `main button` 里文本为「保存」的最后一个。
- 只改一个区块后点保存，另一个区块的未保存改动会被一起提交（同页两套状态），
  所以**一次只动一个区块**，改完再动下一个。

实测记录（门店「演示门店」，2026-10-29 22:58）：

| | 改前 | 改后 |
|---|---|---|
| 不参与占座 | 0/0 无数据 | **0/1 = 068** |
| 参与占座 | 0/7（068、A001、A002（包间2）、A003、WIN-6M29LC76S4U、WinPC-1YCGCRS、yunchen-pc） | 0/6 |
| 不参与订座 | 0/7（同上 7 台） | 未动 |
| 参与订座 | 0/0 | 未动 |

注意：本店**订座侧 7 台全在「不参与订座」**，等于订座功能实际没生效（与全局开关是否打开无关，
机位这一侧没放行）。要开订座必须先把机位从左框移到右框，再点保存。

脚本：`scripts/toggle-seat.js`，改 `TARGET` / `MODE` / `ACTION` 三个常量即可，默认 DRY_RUN。


### 6.3 通知与宣传 `/serviceManage/notice/*`

通知 `noticeRecord`：列 标题 / 内容 / 通知时间 / 状态 / 原因 / 审核时间；按钮 新 增 / 删除。
宣传 `promotion`：列 标题 / 内容 / 展示开始时间 / 展示结束时间 / 状态 / 更新时间；按钮 添加 / 查看。

通知**需要审核**（有「原因 / 审核时间」列），宣传不需要。要马上触达用宣传。

## 七、账目管理 `/netBarSummary/handOver`

交接班列表列：交班人 / 交班时间 / 上缴金额 / 留给下班 / 移动收入 / 核销收入 / 总收入。筛选：交班人、交班时间。
顶部汇总：上缴金额 / 移动收入 / 核销收入 / 总收入。

口径：

- **上缴金额**：当班交给店里的现金。
- **留给下班**：留在钱箱的备用金。
- **移动收入**：微信/支付宝/团购等线上收款。
- **核销收入**：团购券核销折算的收入。
- **总收入** = 上缴 + 移动 + 核销（不含留给下班）。

实测当日四个数均为 0，说明还没有真实营业流水，做对账演示时要注意别拿 0 当结论。

## 八、红线

- **提现、买短信、买桌贴都是真实资金/采购**，非老板授权不要点。
- **收款账号停用期间收不到钱**，换卡要选低峰时段。
- **服务号授权解绑会导致会员收不到通知**，解绑前先告知。
- 交接班金额只读，口径错只能靠备注说明，不能改数。

## 九、校验清单

| 检查项 | 期望 |
|---|---|
| 场所审核状态 | 未通过则支付/团购不可用 |
| 商超总开关是否开 | 关了前端看不到商超 |
| 移动端别名是否已改 | 否则对外显示「测试」 |
| 自助充值/办会员开关 | 决定 app 上能不能自助 |
| 专场卡配置是否启用 | 卡建了不启用照样卖不了 |
| 短信余额 | 短信预警与验证码依赖它 |
| 提现前核对可提现金额 | 赠送部分不可提 |
