# 旺云商户端 · 区域费率查询技能手册 v1

> 站点 wyb.5188cloud.net，门店「演示门店」（placeCode 00000000000000）。
> 页面：计费设置 → 区域方案，路由 `/msBarOptions/area`。
> 状态：2026-10-29 22:30 实测读取，页面只读。
> 用途：给 AI 读取「每个区域收多少钱」，并为后续改价、对账、定价复盘提供基准快照。

---

## 一、结论先行

1. 全场共 **8 个区域**，但只挂了 **4 套方案**，改一套会影响多个区域。
2. 每个区域有 **4 个客户档位**：临时卡 / 计费会员卡 / 计时会员卡 / 连锁会员卡，费率各自独立。
3. 计费方式统一是「按[每小时]和[包时段]的最小值计费」，**24 小时 × 7 天费率明细全部同值**，即没有分时价、没有夜间加价。
4. 页面顶部固定提示「当前版本无法修改区域方案」——**这里改不了价，只能看**，改价必须走平台（旺云）侧。
5. 数据里存在 3 处量级矛盾（见第六节），汇报时必须带上，不要直接把「单位价」当成实际每小时收费。

## 三、页面结构

- 左侧竖排区域列表：默认区域、曲屏区域、电竞区、包间1、包间2、大厅、包间3、包间4
- 右侧两个 tab：**费率设置**（默认）/ 其他设置（区域名称、允许会员等级、允许上网卡）
- 费率设置内再分 4 个客户档位 tab + 两块内容：
  - **基础方案**：计费方式、忽略时间、半点有效、起步价、单位、折扣
  - **费率明细**：周一~周日 × 0~23 点的网格
  - **包时段策略**：开始时间、结束时间、价格、星期、收现金、操作

## 四、字段语义（实测口径）

| 字段 | 含义 | 单位 |
|---|---|---|
| 计费方式 | 「按[每小时]和[包时段]的最小值计费」= 两种算法取便宜的那个 | — |
| 忽略时间 | 上机后前 N 分钟不收费 | 分钟 |
| 起步价 | 一次开台的最低消费 | 元 |
| 单位 | 单位价（后端 iUnit，接口按分存，100 = 1 元） | 元 |
| 折扣 | 100 表示不打折 | % |
| 费率明细 | 每个时段一格，全时段同值说明无分时价 | 见第六节 |
| 包时段策略 | 23:00-07:00 这类一口价包夜 | 元 |

接口字段对照（`/msbar/billing_policy/area/rules` 的 `data.rule`）：

- `temp` → 临时卡
- `fee` → 计费会员卡
- `time` → 计时会员卡
- `chain` → 连锁会员卡
- 每档内含 `iMinFee`（起步价）、`iUnit`（单位价）、`iRebate`（折扣）、`iIgnoreTime`（忽略时间）、`iHalfIgnore`（半点有效），**金额全部以「分」为单位**
- `data.details[]` → 包时段策略，`iprice` 单位分，`iuseTimeb/iuseTimee` 单位秒，`bboRule=1` 是页面会显示的那几条

## 六、三处必须一起汇报的矛盾

**1. 电竞区 / 包间1 / 包间2：单位价 1 元，费率明细 60。**
若按「单位 × 倍数」，等于 60 元/小时；但包夜 48 元 / 8 小时 ≈ 6 元/小时，两者差 10 倍。合理猜测是费率明细以「角」或「分」为刻度（60 → 6 元），但**未验证前不要写死**。

**2. 大厅：单位价 2 元，费率明细 10。**
按倍数是 20 元/小时，与大厅在售的 5 小时包时卡 28.8 元（≈5.8 元/小时）、早场卡 9.9 元、上午/下午各 10 元对不上。

**3. 默认区域 / 包间3 / 包间4：费率明细只有 1。**
按 0.1-1 元/小时算近乎免费，疑似占位配置。门店名是「演示门店」，这三个区可能没在真实使用。

**结论口径**：对外汇报时写「后台配置值」，不要直接换算成「每小时实收」。要坐实小时价，只有两条路——开一张 1 元临时卡在目标区上机 20 分钟看实扣（会产生真实账单，须用户同意），或直接问门店老板。

## 七、读数据的两个坑（都踩过）

**坑1：裸 fetch 接口报 `{"code":406,"message":"非法访问"}`。**
接口要签名/鉴权头，页面内 `fetch` 不带，直接失败。正确做法是用 Playwright 拦截页面自己发出的请求：

```js
const p = page.waitForResponse(r => r.url().includes('billing_policy/area/rules') && r.status()===200, {timeout:15000});
await page.getByText('电竞区', {exact:true}).first().click({force:true});
const data = (await (await p).json()).data;
```

**坑2：按 tab 点开再读网格，会读到上一个区域/上一档的残留值。**
Element UI 的 tab-pane 是全量渲染后隐藏，`offsetParent`、`getBoundingClientRect().height` 都判不准；切换区域时旧 pane 还在 DOM 里。表现出来就是：默认区域读完，切曲屏，率值还是 1；电竞区读到 60 却以为是 1 元档。
规避法：先按区域点一次、再按档位点一次，各自 `waitForTimeout(1000+)`，然后用 `getBoundingClientRect().height > 0 && innerText.includes('起步价')` 双条件取当前可见 pane；或者干脆只信接口的数字。

## 九、校验清单

| 检查项 | 期望 |
|---|---|
| 8 个区域是否全部读到 | 缺一个说明菜单名改了或区域被删 |
| 方案数是否仍为 4 | 变多说明新增了独立方案，改价影响面要重算 |
| 费率明细是否 24×7 同值 | 出现不同值说明新配了分时价，报价逻辑要改 |
| 折扣是否全 100 | 出现非 100 说明某档在打折 |
| 包夜价 ÷ 时长 与费率明细是否同量级 | 差 10 倍就是第六节的矛盾，先问清楚再报数 |

## 十、延伸

- 上网卡（计费设置 → 上网卡）里能看到包时卡的真实售价，可用来反推某区域的小时价：`5小时包时 = 300 分钟 / 28.8 元 / 使用区域 大厅`。
- 限价策略（计费设置 → 基础设置 → 限价策略）有「会员卡最小费率」「临时卡最小费率」，是平台侧的价格下限，与区域费率互不影响。
- 会员等级（计费设置 → 会员等级）管折扣，区域方案管基准价，两层叠加后才是会员实付。

## 十一、按机位号查价（068 实测路径）

问题形态：「068 这个机位普通会员多少钱一小时、通宵多少」。四步走，缺一步就会答错。

**第 1 步 机位号 → 所属区域**
计费设置 → 终端管理（`/msBarOptions/clients`）→ 终端列表，列头即「序号 / 机位 / IP地址 / 客户端版本 / 所属区域」。

实测：`068 = 192.168.1.253 = 大厅`。

注意机位号不一定是纯数字，列表里还有 `A001`、`WIN-6M29LC76S4U`、`WinPC-1YCGCRS`、`yunchen-pc`。用户给的名字要和「机位」列精确匹配。

**第 2 步 区域 → 方案**
回区域方案，用第三节的方案映射表换算。068 落大厅，大厅是独占方案，只影响自己。

**第 3 步 会员身份 → 档位 + 等级折扣**
两层叠加，不是一层：

| 层 | 在哪看 | 大厅取值 |
|---|---|---|
| 档位基准价 | 区域方案 → 计费会员卡 tab → 基础方案 | 起步 2 元 / 单位 2 元 |
| 等级覆盖 | 同 tab 下方等级按钮（默认费率 / 普通[计费] / 美团新会员 …） | 普通[计费] 显示 起步 5 / 单位 1 |
| 等级折扣 | 计费设置 → 会员等级 → 上机费用折扣 | 普通[计费] = 100（不打折）；美团新会员 = 88 |

「普通会员」在系统里的名字是 **普通[计费]**，不是「普通会员」，搜的时候要用方括号原名。

**第 4 步 看红字提示，决定用哪套数**
选中等级后，费率明细上方会出现红字：
- 出现「未单独设置等级扣费方案，使用默认值」→ 该等级没配独立方案，**按档位基准价算**，等级面板里的 5/1 只是残留显示，不生效。
- 没出现红字 → 按等级面板的数值算。

这一步是全场最容易漏的。068 就命中了红字，所以应取基准价 起步 2 元 / 单位 2 元。

**通宵价怎么答**
先查该区域有没有包夜包时段（bboRule=1）。大厅 **没有**，所以通宵只能按小时计：23:00-07:00 共 8 小时。

其次查上网卡里有没有能覆盖通宵的专场卡（大厅可用）：
- 上午 10 元 / 00:00-12:00 → 可覆盖 00:00-07:00
- 下午 10 元 / 12:00-24:00
- 早场卡 9.9 元 / 07:00-12:00 / 全部区域
- 5小时包时 28.8 元 / 300 分钟 / 大厅
- 18-20点 20 元 / 大厅

所以大厅通宵的实操答法是「无包夜价，按小时计约 16 元；想省钱走『上午』专场卡 10 元」。

**回填时的口径**
回答必须区分「后台配置值」和「实际扣费」，并说明置信度来源。数值打架时，以「红字提示 + 包时卡反推」优先，不要直接报 单位价 × 费率明细。
