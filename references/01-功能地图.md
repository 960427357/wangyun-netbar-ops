# 旺云商户端 · 功能地图技能手册 v1

> 站点 wyb.5188cloud.net，门店「演示门店」，placeCode 00000000000000。
> 状态：2026-10-29 实测，菜单树取自 `/api/netbarMenus` 接口原始响应，路由为逐页验证。
> 用途：任何「某功能在哪」的问题，先查这份地图，不要瞎点。

---

## 一、结论先行

1. 全站 **9 个一级模块 / 约 45 个二级 / 约 100 个叶子页**，是三段式导航：左侧一级 → 顶部二级 → 内层三级（tab 或侧栏）。
2. 路由规律：`一级/二级/三级`，如 `/marketManage/goodsManage/shop/goods`。**二级路径本身不是页面**，直接访问会回落到默认页。
3. 有一批页面是**平台只读**，页头固定提示「当前版本无法修改…」，改不了，别浪费时间：计费设置全 7 页、区域方案、会员等级、上网卡。
4. 拿菜单树最省事的办法是截 `/api/netbarMenus` 响应，不要靠点击猜。

## 二、导航与抓取

### 2.1 三种导航方式

| 方式 | 做法 | 适用 |
|---|---|---|
| 点左侧 | `.menu-item` 一级 → 顶部 `.menu-box .menu-item` 二级 → 内层 tab | 手工操作 |
| 直连路由 | `page.goto('/msBarOptions/area')` | 脚本，最快最稳 |
| 截接口 | `netbarMenus`（菜单树）、各页业务接口 | 批量、结构化 |

### 2.2 点击的两个坑

**坑1：`.menu-item` 同时命中左侧一级和顶部二级。** 左侧每项 56px 宽、x≈7；顶部二级在 x>100。按 `getBoundingClientRect().left` 区分。
**坑2：点一级模块不一定立即切换。** 若上一步刚点过二级，顶部条可能仍是上一个模块的菜单，读出来就是错的。稳妥做法是直连路由。

### 2.3 菜单树来源

```js
const p = page.waitForResponse(r => r.url().includes('netbarMenus'), {timeout:25000});
await page.reload({waitUntil:'domcontentloaded'});
const d = (await p.json()).data;   // d.menus 是树，d.resources 是权限点
```

`d.menus` 每层字段：`name`（显示名）+ `path`（路由片段）+ `children`。

## 四、只读页清单（别答应改）

页头出现「提示：当前版本无法修改…」的页面，说明当前套餐/版本锁死：

- 计费设置：基础设置、区域方案、会员等级、上网卡
- 其余模块未见该提示，可正常增删改

看到这个提示还要改价、改等级，只能走平台（旺云）客服侧，或先查店铺是否处于试用/低版本套餐。

## 五、页面要素抓取模板

需要给任意页面拍「结构快照」时用这段，能一次拿到 tab、按钮、列头、表单标签：

```js
const grab = () => page.evaluate(() => {
  const vis = e => { const r = e.getBoundingClientRect(); return r.height > 0 && r.width > 0; };
  const txt = e => (e.innerText || '').replace(/\s+/g, ' ').trim();
  return {
    path: location.pathname,
    tabs: [...new Set([...document.querySelectorAll('.el-tabs__item')].filter(vis).map(txt))],
    btns: [...new Set([...document.querySelectorAll('main button, .el-button')].filter(vis).map(txt))],
    ths:  [...new Set([...document.querySelectorAll('.el-table__header th')].filter(vis).map(txt))],
    labels: [...new Set([...document.querySelectorAll('.el-form-item__label')].filter(vis).map(txt))],
    tip: (document.body.innerText.match(/提示：[^\n]{0,50}/) || [''])[0]
  };
});
```

配套脚本：`scripts/crawl-pages.js`（按路由批量抓页面）、`scripts/crawl-dialogs.js`（打开新增弹窗抓字段，只读不存）。

## 六、校验清单

| 检查项 | 期望 |
|---|---|
| 直连某二级路径是否回落到默认页 | 回落说明该层级无页面，要用三级完整路径 |
| 页面是否只读 | 有「当前版本无法修改」提示就是只读 |
| 是否为拼写错误路由 | `gruopWriteOff` 这类照抄，别「纠正」 |
| 顶部二级是否属于当前模块 | 上一步点击残留会导致串模块，保守做法直连路由 |
