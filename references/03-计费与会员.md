# 旺云商户端 · 计费与会员配置技能手册 v1

> 路由前缀 `/msBarOptions`，门店「演示门店」，placeCode 00000000000000。
> 状态：2026-10-29 实测。整块当前为**只读**（页头提示「当前版本无法修改…」），本文记录字段语义与设置路径，供升级版本后或平台侧操作时对照。

---

## 一、结论先行

1. 计费设置共 7 页，构成一条完整链路：**基础设置（开关）→ 区域方案（价）→ 会员等级（折扣）→ 上网卡（卡种）→ 充值活动（赠送）→ 终端（机位）→ 控制台（收银台）**。
2. 价格不是一个数，是三层叠出来的：`区域基准价（起步价+单位价）× 费率明细 × 等级折扣`。任何一层没看全，报价都会错。
3. 「允许修改金额」「最小收费单位」「限价策略」是**价格护栏**，配错会让收银员改不了价或改出离谱价。
4. 基础设置里「其他」页签藏着最多行为开关（换机、包时段、报余额、审核），排查「为什么会有这个提示音/允许换机」先来这里。

## 三、基础设置 8 个页签

### 3.1 临时卡

| 字段 | 含义 |
|---|---|
| 从临时卡激活 N 分钟后，到开始上机之间进行计费 | 开卡未上机的空窗是否计费 |
| 从临时卡激活后，到开始上机之间，按 X 元/小时 | 空窗期费率 |
| 最小收费单位 | 空窗期最少收多少 |
| 未上机则过 N 分钟自动取消激活（0 = 不取消） | 防占机 |
| 临时卡只能在开卡控制台退卡 | 退卡权限收口 |
| 临时卡包时段结束后自动下机 | 包夜到点踢机 |
| 临时卡使用证件号后 6 位作为密码 | 免设密码 |
| 临时卡密码（默认 999999） | 统一密码 |
| 允许临时卡移动充值 | 收银端能否给临时卡充值 |
| 临时卡开卡时打印小票。网吧名称： | 小票抬头 |

### 3.2 会员卡

| 字段 | 含义 |
|---|---|
| 从计费会员卡激活 N 分钟后计费 | 同临时卡的空窗规则 |
| 会员卡激活时自动确定（等级/价格） | 激活即锁等级 |
| 会员卡包时段结束后自动下机 | 包夜踢机 |
| **会员卡包时段不打折** | 包夜的固定价不再乘折扣，避免叠加 |
| 非实物卡会员上机前必须在控制台激活账号 | 虚拟卡也要激活 |
| 使用充值积分 | 充值是否给积分 |
| 本连锁分店不允许办理本地会员 | 连锁场景 |

### 3.3 专场卡

`专场卡开卡后立即扣费 / 会员激活允许使用专场卡 / 激活时附加专场卡只收现金 / 附加专场卡允许使用现金余额 / 附加专场卡允许使用赠送余额（优先扣现金）/ 一体机会员激活不允许办专场卡`

关键：**「只收现金」和「允许用赠送余额」互斥**，同时开会出账务争议。

### 3.4 包间

`包时段费用不允许 AA 分摊 / 上机起步费不允许 AA 分摊 / 在线预订（占座、订座）费用不允许 AA 分摊`

三个 AA 开关，包间多人分摊时用。

### 3.5 无人值守

`启用无人值守自动上机` — 开了才能刷脸/扫码自助上机。

### 3.6 交接班

`账户变动信息只在对应控制台显示` — 多收银台场景下隔离账目。

### 3.7 其他（最重要的一页）

| 分组 | 开关 |
|---|---|
| 交互 | 收现金包时段不提示 / 弹窗到最前面 / 图标闪烁提醒 / 发送旺旺吧网吧版 APP 通知 |
| 语音 | 会员卡激活、取消激活时报余额 / 续费充值时报余额 / 报余额时同时报会员等级 / 临时卡开卡时报押金 / 临时卡结账时报余额 / 客户机余额不足 |
| 换机 | 不允许换机 / 允许直接换机（不需客户端请求）/ 不允许跨区域换机 / 不允许包时段跨区域换机 / 包时段跨区域换机以最高费用计费 |
| 扣费 | 包时段只扣现金 / 请客不能用赠送账户 |
| 计费方式（5 选 1） | 0. 按上机区域设置 / 1. 按每小时计费 / 2. 按包时段计费 / 3. 按 1 和 2 最小优先 / 4. 指定时间下机 / 5. 指定上机时长 |
| 支付 | 优先选择移动支付 / 移动支付位置靠前 |
| 结算 | 更改收费方案后，结算之前的费用（扣费方案、费率方案、折扣变动） |
| 审核 | 不允许跨班次审核（开启后交接班自动拒绝当班申请） |
| 流水 | 允许修改"应该充值"金额 / 允许自定义流水号 / 临时卡自动随机流水号（5 位）/ 临时卡自动随机密码 / 会员卡自动生成 N 位流水号 |

**计费方式那一组是全局默认**，区域方案里的「按每小时和包时段取最小」是区域级覆盖，两级优先级：区域 > 全局。

### 3.8 限价策略（价格护栏）

| 字段 | 含义 |
|---|---|
| 特定时段 1/2 费率（元）+ 开始/结束时间 | 两个自定义时段的统一费率 |
| 会员卡最小费率（元） | 会员价不得低于此值 |
| 临时卡最小费率（元） | 临时价不得低于此值 |
| 最小收费单位 | 计费粒度 |
| 起步价（元） | 全局兜底起步价 |
| 忽略时间（分钟） | 全局兜底免费时长 |
| 赠送方式 | 赠送金额的记账口径 |

区域方案里的同类字段与这里冲突时，以区域为准，这里是兜底。

## 四、区域方案的价怎么算

```
单次实收 = max(起步价, 停留小时数 × 单位价 × 费率明细倍数) × 折扣%
包夜时   = min(按小时算出的钱, 包时段固定价)
```

实测取数见《04-区域费率.md》。三点必须记住：

1. 方案共用：默认方案 → 默认区域/包间3/包间4；包间 → 电竞区/包间1/包间2；曲屏方案 → 曲屏区域；大厅 → 大厅。
2. 费率明细 24×7 同值 = 无分时价；出现不同值说明配了峰谷价。
3. 费率明细的**量级与单位价不一致**（电竞 60 vs 单位价 1），这是未解问题，不要直接把两者相乘当报价。

## 五、会员等级

三 tab：计费会员 / 计时会员 / 连锁会员。列与语义：

| 列 | 语义 |
|---|---|
| 等级名称 | 系统原名带方括号，如「普通[计费]」，搜索要用原名 |
| 晋级积分 | 达到该等级所需累计积分 |
| 积分增加 | 消费时积分倍率 |
| 充值积分增加 | 充值时的积分倍率 |
| **上机费用折扣** | 100 = 原价，88 = 八八折 |
| 自动晋级 / 自动降级 | 达标自动升降 |
| 等级说明 | 展示用文案 |

实测等级：普通[计费] 0 分 折扣 100、美团新会员 3 分 折扣 88、抖音新会员 4 分 100、团购新会员 5 分 100、女神卡 20 分 100、钻石会员 100 分 100、1111 500 分 100。

**「普通会员」= 普通[计费]**，不是「普通会员」四个字。

## 六、上网卡

三 tab：专场卡 / 临时卡 / 会员卡。行内要点：

| 字段 | 语义 |
|---|---|
| 计费类型 | 固定时长（按分钟）/ 固定时段（按起止时间） |
| 押金 / 预付款 | 卡的售价 |
| 时间(分钟) | 固定时长卡的总时长 |
| 开始/结束时间 | 固定时段卡的可用窗口 |
| 提前开卡时间 / 停止开卡时间 | 售卖窗口 |
| 退卡不退费时间 | 超过 N 分钟退卡不退钱 |
| 过期时间 | 长期有效 或指定日期 |
| **使用区域** | 决定这张卡能在哪些区刷 |

实测：5小时包时 28.8 元 / 300 分钟 / 大厅；专场卡 1.9 元 / 120 分钟 / 大厅；5分钟测试卡 29.9 元 / 全部；上午 10 元 00:00-12:00 / 大厅；下午 10 元 12:00-24:00 / 大厅；18-20点 20 元 / 大厅；早场卡 9.9 元 07:00-12:00 / 全部。

**专场卡是绕开会员体系做低价时段的工具**，报价时优先看它，往往比按小时便宜得多。

## 七、终端管理

两 tab：终端列表 / 客户端设置。列：序号 / 机位 / IP地址 / 客户端版本 / 所属区域。

改机位区域 = 改这台的费率来源。实测 7 台终端，068 在大厅。

## 八、控制台设置

两 tab：计费控制台 / 旺云控制台。列：序号 / 控制台名称 / 计算机名称 / 绑定状态 / 客户端 / IP地址。

绑定状态决定收银端能不能开卡、上机、退卡。控制台没绑定，前台就是空转。

## 九、按机位查价的四步（复述，含坑）

1. 终端管理 → 机位 → 所属区域
2. 区域方案 → 该区域所属方案 → 档位（临时卡 / 计费会员卡）
3. 会员等级 → 该等级的「上机费用折扣」
4. **看价格页上方的红字提示**：出现「未单独设置等级扣费方案，使用默认值」时，等级面板里显示的数字不生效，按档位基准价算

## 十、校验清单

| 检查项 | 期望 |
|---|---|
| 7 页是否都能打开 | 打不开说明无权限或路由变更 |
| 区域方案与限价策略是否冲突 | 区域价低于限价最小值会被拦 |
| 会员折扣是否与基准价匹配 | 折扣后低于最小费率会结算异常 |
| 专场卡使用区域是否存在 | 区域被删会变成孤儿卡 |
| 终端所属区域是否存在 | 否则上机取不到价，按 0 计费 |
| 控制台绑定是否正常 | 未绑定则无法开卡 |
