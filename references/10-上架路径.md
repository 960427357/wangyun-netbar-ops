## 三、商品上架三条路径（按效率排序）

### 路径 A：单品新增（最稳，推荐脚本化）
销售管理 → 商超管理 → 基础管理 → 商品名称 → 添加
- 路由 `/marketManage/goodsManage/baseManage/goodsName`
- 弹窗「添加商品」字段
  - 商品名称（必填，placeholder `请输入商品名称`）
  - 商品图片（可选，jpg / png / jpeg，≤500KB）
- 按钮：取消 / 继续添加（连录保持弹窗）/ 确认

### 路径 B：批量导入（一次 ≤100 种）
销售管理 → 商超管理 → 商品管理 → 导入 → 旺云数据
- 路由 `/marketManage/goodsManage/shop/goods`
- 弹窗「导入文件（旺云数据）」：浏览 → 选择文件 → 上传数据
- 限制：单次不超过 100 种商品，上传后不可离开本页
- 注意：界面未提供模板下载，需导出既有商品反推列格式，或向平台客服索取模板

### 路径 C：表格内联编辑（存量商品维护）
商品管理表格可直接改 进货价 / 销售价 / 兑换所需积分，用 +/- 调库存，行内操作 补货 / 编辑 / 删除 / 下架 / 报损

## 五、自动化运行方式

已登录的 playwright-cli 有头会话中执行：

```bash
# 1. 确认会话在线
playwright-cli list

# 2. 运行批量新增脚本（把商品清单写进 scripts/add-goods.js 的 products 数组）
playwright-cli run-code --filename scripts/add-goods.js
```

脚本骨架见 `scripts/add-goods.js`。核心逻辑为循环：点「添加」→ 填名称 → 可选传图 → 非末条点「继续添加」、末条点「确认」。

## 六、风险提示

- 图片上传走 `input[type=file]`，若弹窗用自定义上传组件需改用 `setInputFiles` 定位。
- 批量导入的列格式未公开，导入前务必先用 1 到 2 条做试运行。
- 站点为生产后台，脚本应加逐条结果校验，避免静默失败。
