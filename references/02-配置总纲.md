# 旺云商户端 · 门店配置总纲技能手册 v1

> 站点 wyb.5188cloud.net，门店「演示门店」。
> 状态：2026-10-29 实测，字段来自逐页抓取（scripts/crawl-pages.js / scripts/crawl-dialogs.js）。
> 用途：回答「这个功能怎么设置」「改这个会不会影响别的」，先看依赖顺序，再动手。

---

## 一、结论先行

1. 配置有严格依赖顺序：**先场所 → 再计费方案 → 再会员等级/卡 → 再终端 → 再网吧配置 → 再员工权限 → 最后营销**。顺序颠倒会出现「选了没选项」「存了不生效」。
2. 三类东西最容易乱：**区域方案**（管价）、**会员等级**（管折扣）、**网吧配置**（管开关）。价格 = 区域基准价 × 等级折扣，开关 = 网吧配置。三者互不覆盖，缺一个都不对。
3. 当前门店的计费设置整块是**只读**（版本锁定），配置层面的实操只能改「基础设置 / 员工 / 营销 / 商品」这些模块。
4. 每个模块改完都要回列表页刷新复核，页面有大量「保存了但没生效」的情况。

## 二、配置依赖链

```
① 场所管理（/admin/systemSetting/place）          门店主体、审核状态、场所编号
        ↓
② 区域方案（/msBarOptions/area）                  8 个区域 × 4 档费率；决定每小时/包夜价
        ↓
③ 会员等级（/msBarOptions/levels）                等级 + 晋级积分 + 上机费用折扣
        ↓
④ 上网卡（/msBarOptions/cards）                   专场卡/临时卡/会员卡 的售价与可用区域
        ↓
⑤ 终端管理（/msBarOptions/clients）               客户端与机位绑定、所属区域
        ↓
⑥ 网吧配置（/admin/systemSetting/netbarConfig/*） 8 个开关页，决定前端能不能自助购买/充值/订座
        ↓
⑦ 员工（部门→岗位→角色→员工→绩效/激励/打赏/OA）  权限与提成
        ↓
⑧ 商品（分类→名称→吧台→预警→入库→上架）          商超销售
        ↓
⑨ 营销（促销人群/策略 → 券/充值赠 → 活动/礼包）    拉新与复购
```

### 为什么是这个顺序

| 依赖 | 说明 |
|---|---|
| ③ 依赖 ② | 会员折扣是乘在区域基准价上的，区域没配好，折扣算出来是错的 |
| ④ 依赖 ② | 专场卡要选「使用区域」，区域缺失就选不到 |
| ⑤ 依赖 ② | 终端要归属区域，否则上机取不到费率 |
| ⑥ 依赖 ④⑤ | 移动端/订座/专场卡配置里勾选的卡和区域，必须先存在 |
| ⑦ 依赖 ① | 员工挂在部门和岗位上，部门没建就没得选 |
| ⑧ 依赖 ⑥ | 「是否开启商超」关着，商品配了也不在前端露出 |
| ⑨ 依赖 ③⑧ | 促销人群按等级圈人，券按商品/场景抵扣 |

## 三、九个模块的配置入口与标志字段

### ① 场所 - `/admin/systemSetting/place`

列表：场所名称 / 审核状态 / 场所类型 / 场所编号 / 场所地址，按钮有「绑定 / 查看 / 编辑」。
`场所编号` 就是接口里的 placeCode，后面所有计费接口都带它，改配置时对不上号先查这里。

### ② 区域方案 - `/msBarOptions/area`

8 区域 × 4 档（临时卡/计费会员卡/计时会员卡/连锁会员卡），字段：计费方式、忽略时间、起步价、单位、折扣、费率明细、包时段策略。
详见《04-区域费率.md》。

### ③ 会员等级 - `/msBarOptions/levels`

三个 tab：计费会员 / 计时会员 / 连锁会员。
列：等级名称 / 晋级积分 / 积分增加 / 充值积分增加 / **上机费用折扣** / 自动晋级 / 自动降级 / 等级说明。
实测：「普通[计费]」折扣 100（不打折），「美团新会员」88 折。

### ④ 上网卡 - `/msBarOptions/cards`

tab：专场卡 / 临时卡 / 会员卡。
关键列：专场卡名称 / 计费类型（固定时长·固定时段）/ 押金 / 预付款 / 时间(分钟) / 开始时间 / 结束时间 / 提前开卡时间 / 停止开卡时间 / 退卡不退费时间 / 过期时间 / **使用区域** / 排序。
实测在售：5小时包时 28.8 元 300 分钟 大厅、专场卡 1.9 元 120 分钟 大厅、早场卡 9.9 元 07:00-12:00 全部区域。

### ⑤ 终端管理 - `/msBarOptions/clients`

两个 tab：终端列表 / 客户端设置。
列：序号 / 机位 / IP地址 / 客户端版本 / 所属区域。实测 7 台：068→大厅、A001→大厅、A002→包间2、A003→大厅、WIN-6M29LC76S4U→默认区域、WinPC-1YCGCRS→默认区域、yunchen-pc→默认区域。

### ⑥ 网吧配置 - `/admin/systemSetting/netbarConfig/*`

八个 tab，这是**唯一能改开关的地方**，全部「保 存」生效：

| Tab | 路由 | 核心开关 |
|---|---|---|
| 基础配置 | `.../base` | 允许吧台改商品价、会员余额买商品、客户端充值自定义金额、是否开启商超、自动打印小票、支付方式（现金/微信/支付宝/POS）、超时撤销核销、自助办会员、交接班强制查现金未派送 |
| 充值策略 | `.../recharge` | 策略名称 / 会员类型 / 充值金额 / 赠送金额 / 会员等级 / 会员日 / 网民自助购买 / 充值次数 / 适用场景 |
| 移动端配置 | `.../wwbao` | 是否上架旺旺宝网吧版、是否允许办会员、别名、联系电话、人均消费、服务标签、营业状态、营业时间、电脑配置、室内图片 |
| 订座配置 | `.../orderSeat` | 占座配置 / 订座配置，会员 / 临时卡 / 现金 / 现金+赠送 四类支付 |
| 专场卡配置 | `.../specialCardSet` | 专场卡名称 / 是否启用 / 允许网民自助购买 / 支持余额支付 / 销售对象 / 可用时间 |
| 一体机配置 | `.../ytjSet` | 一体机相关 |
| 补贴策略设置 | `.../subsidyStrategy` | 等级 / 赠送网费（新增·编辑·删除） |
| 电脑配置 | `.../computerConfig` | 电脑名称 / 区域 / 配置信息，支持批量设置、区域设置 |

## 四、改配置的通用流程

1. 确认目标页是否只读（页头有无「提示：当前版本无法修改」）。
2. 确认该页的上级依赖是否就绪（查第二节依赖链）。
3. 改完点页面上的「保 存」——**不是所有页面都有保存按钮**：
   - 表单型页面（网吧配置、核销设置、打赏设置、促销规则）有「保 存」。
   - 列表型页面（部门、角色、员工、礼包）走弹窗「确定」。
   - 商品管理的内联库存框是**失焦即存**，没有按钮。
4. 刷新复核。列表页 F5 后值还在才算落库。
5. 涉及钱的操作（改价、改折扣、发券、发礼包）先 dry-run 报数给用户确认。

## 五、红线

- **不要在只读页反复尝试保存**，会误判成「操作失败」，其实是版本限制。
- **不要跳步**：区域方案没定就配专场卡，卡会绑到错区域；部门没建就加员工，岗位选不到。
- **不要只改一处**：改区域价后，检查会员等级折扣、专场卡售价、充值赠送是否还成立。
- **改价影响面看方案共用**：电竞区/包间1/包间2 共用「包间」方案，改一个动三个。

## 六、校验清单

| 检查项 | 期望 |
|---|---|
| placeCode 与场所编号一致 | 不一致说明看的是别的门店数据 |
| 区域方案改动后 4 档是否都看 | 只改一档会导致会员价与临时价倒挂 |
| 会员等级折扣是否与新价匹配 | 折扣 + 基准价 = 实付，任一变都要重算 |
| 网吧配置开关是否有前置数据 | 开商超前必须有商品分类与吧台 |
| 员工新增后能否登录 | 有手机号+密码+角色才可登录，缺角色先加角色 |
